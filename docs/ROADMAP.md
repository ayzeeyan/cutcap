# CutCap roadmap

These are dependency-ordered milestones with exit evidence, not delivery dates. Phase 0 established the native shell/model. Phase 1 adds real import, metadata and cancellable source still-frame seeking; see PHASE_1_REPORT.md for evidence and limits. The frontend has since moved from Slint to Avalonia over a versioned C ABI with Phase 1 behavior preserved (AVALONIA_MIGRATION_REPORT.md); milestones below are unchanged in scope, and UI work now lands in apps/CutCap.Desktop while engine work stays in Rust.

| Milestone | Scope and exit evidence |
|---|---|
| 1 — Import and source still-frame preview | Implemented using owner-authorized external development FFmpeg/FFprobe 9.0.1, bounded probe/decode, actual metadata/library entries, CPU preview and source seeking. CFR/VFR/offset/orientation fixtures, cancellation/stale-result/resource tests and measurements are recorded in PHASE_1_REPORT.md. No FFmpeg redistribution clearance or arbitrary-codec frame-accuracy promise. |
| 2 — Source playback engine / frontend integration | Implemented persistent framed decoding, clock, bounded queues, transport and Phase 2B production UI/render-loop pumping. Phase 3A corrects the false startup Buffering state using real preroll readiness; due-frame deadlines stay unchanged. Smooth locked 30/60 FPS and physical scanout are not established. Profile gaps on actual displays before a measured pacing change or GPU interop; no speculative vsync policy. |
| 3A — Reliable project persistence and stabilization | Implemented `.cutcap` envelope 1/core schema 1, bounded validated Open, captured-revision background Save/Save As, synced same-directory replacement, source fingerprints/re-probe/missing states, original-content relink, ABI 3 and unsaved confirmation. Integrity and OS/filesystem limits: PROJECT_FORMAT.md. Evidence: PHASE_3A_PROJECT_PERSISTENCE_REPORT.md. Autosave/backups/external-writer conflict handling remain future work. |
| 3B — First timeline edits | Implemented Rust-owned append-to-end clip insertion, removal, transient clip selection, bounded exact undo/redo with saved-revision-correct dirty state, ABI 4 with a separately fetched timeline document, and Avalonia clip drawing/selection/Delete/Ctrl+Z/Ctrl+Y with viewport culling. Evidence: PHASE_3B_TIMELINE_EDITING_REPORT.md. No drag, trim, split, move, timeline playback or composition. |
| 3C — Exact timeline preview | Implemented single-video-track indexed evaluation, half-open cuts/gaps, checked rational timeline-to-source mapping, endpoint-validated real frame decoding, Rust-owned playhead, ruler seeking and independent Source/Timeline modes through ABI 5. No continuous timeline Play/compositing/audio. Evidence: PHASE_3C_TIMELINE_PREVIEW_REPORT.md and PHASE_3C_TIMELINE_PREVIEW_CONTRACT.md. |
| 3D — Video-only timeline playback across cuts | Implemented ABI 6: independent Rust timeline clock, bounded active/next persistent decoders, actual-PTS intervals, cuts/gaps, pause/seek/Stop/replay, structural invalidation and cleanup. Full gates and native two-source/save/reopen/relink/minimum-layout checks pass. Evidence: PHASE_3D_TIMELINE_PLAYBACK_REPORT.md. CPU preview is functional; 4K seek preroll and large-project redraw tails need profiling. No locked-FPS/scanout claim, audio or compositing. |
| Later editing | Trim, split, move (including cross-track), insert at the playhead and grouped undo transactions with deterministic shared preview/export semantics. Test boundaries and overlapping edits. |
| 4 — Audio and synchronization | Device/output selection, bounded audio buffers, resampling and clock ownership; gain/pan and waveforms. Measure A/V drift and underruns. Keep waveform/proxy work cancellable. |
| 5 — Reliable export | One simple preset, explicit stream/timebase/color policy, progress/cancel and safe partial outputs. Compare exported frames/audio/timing to preview evaluation; test independent ffprobe/decode validation and failure cleanup. No unsupported hardware promises. |
| 6 — GPU composition and effects | Measured DX12 path, CPU fallback where practical, device loss, transforms, transitions, basic color/effect stack and cache budgets. Define color/alpha semantics before adding effects. Benchmark representative integrated-GPU projects. |
| 7 — Creative tools | Keyframes, text, typography, masks, speed changes, advanced audio/color and proxies, each with shared preview/export behavior and regression fixtures. Optional local AI only with explicit resource/model licensing and offline controls. |
| 8 — Resilience and public alpha | Autosave/crash recovery, packaging (self-contained win-x64 publish exists; trim the cross-platform Avalonia packages, re-evaluate Native AOT after the SDK advisory is resolved), legal/license/notices review, installer/update policy, accessibility/user testing, project compatibility and measured hardware requirements. Publish only after owner approval and reproducible Windows builds. |

Do not expand into cloud accounts, synchronization or marketplaces to bypass foundational media work. Every milestone includes error paths, memory budgets, tests and documentation. An empty extension trait is not milestone progress.
